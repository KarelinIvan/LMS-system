📅 LMS-system — Образовательная платформа 

Учебный проект по курсу «Python Backend Developer» от Skypro. Веб-приложение для публикации учебных материалов на Django/DRF.

Основные функции
- CRUD: Создание, просмотр, обновление и удаление курсов и уроков через защищённый API (ModelViewSet). Пользователь может работать только со своими публикациями благодаря фильтрации в методе get_queryset.
- Изоляция данных: реализована кастомным разрешением IsOwner.
- Аутентификация: поддержка регистрации с подтверждением e‑mail и авторизации пользователей.
- Эндопоинт подписки: пользователи могут подписываться на обновления своих курсов и уроков.
- Эндопоинт оплаты: интеграция сервиса Stripe для покупки курсов и уроков.

✨ Технологии (Стек) 
- Backend: Python 3.12+, Django 5.1+, Django REST Framework 
- Базы данных: PostgreSQL, Redis 
- Инфраструктура: Docker, Docker Compose 
- Асинхронность: Celery 
- Интеграции: Stripe API, Telegram Bot API 
- Инструменты: Poetry (pyproject.toml), Pytest (coverage), Flake8 (линтер), Swagger (drf-yasg)

🚀 Запуск проекта

Через Docker (рекомендуется)
- Скопируйте переменные окружения из примера: cp .env.example .env Откройте файл .env и заполните секретные ключи (SECRET_KEY, POSTGRES_PASSWORD, STRIPE_API_KEY). Убедитесь, что базы данных нет в .gitignore, иначе она будет создана внутри контейнера.
- Запустите контейнеры: docker-compose up --build

Документация будет доступна тут: http://localhost/docs

Локальный запуск (с Poetry)
- Клонируйте репозиторий: git clone https://github.com/KarelinIvan/LMS-system.git
- Создайте виртуальное окружение и установите зависимости: poetry install
- Примените миграции базы данных: python manage.py migrate
- Создайте суперюзера для админки: python manage.py createsuperuser
- Запустите сервер разработки: python manage.py runserver

Документацию можно открыть тут: http://127.0.0.1:8000/docs

💡 Совет: Для работы интеграции Stripe необходимо получить тестовый ключ доступа к API и указать его в файле .env. Без этого оплата не будет работать.
